Tests and Documentation

Tests/DeskDashboardTests contains framework behavior, theme/layout, observer, interaction, and widget family tests. Shared service doubles live in ServiceStubs.swift.

docs/ contains Pi setup/deploy notes, UI build findings, widget/theme extension guides, progress records, and agent handoffs. These are operational history and contributor context rather than a consumer-facing package manual.

Scripts, Patch, and Assets

  • scripts/start-dashboard.sh starts the dashboard.
  • scripts/build-pi.sh cross-compiles the dev binary.
  • scripts/build-ui-pi.sh performs native low-memory UI builds.
  • scripts/install-kiosk-pi.sh installs kiosk/service configuration.
  • producers/ contains the macOS now-playing push agent.
  • patches/swift-cross-ui-pango-context.patch carries the GTK text measurement optimization.
  • Assets/tea-mist-wide.png is the current dashboard background asset.

Remember Only 3 Things

  1. Start at the layer that owns the behavior, not the file with the visible symptom.
  2. Composition.swift connects the app-specific graph; Package.swift connects the module graph.
  3. GTK-specific behavior is intentionally quarantined under DashboardUI/Support.
