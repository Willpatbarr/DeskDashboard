Build, Test, and Operations Guide

Development, native UI, and kiosk builds are separate because SwiftCrossUI/GTK cannot use static-musl cross-compilation.

Swift Package Products and Targets

Other framework and renderer targets are internal dependencies today, not selectable library products.

Local Development

swift build
swift test
swift run deskdashboard-dev
swift run deskdashboard-ui

The package uses Swift tools 6.3 and Swift language mode 6. The package manifest currently declares macOS 13.

If SwiftPM reports another process using .build, wait for or stop the known build process. Do not delete build state blindly while another process is active.

Raspberry Pi Build Split

Static development binary

scripts/build-pi.sh cross-compiles the dependency-light development executable with the static-musl SDK.

Native GTK UI

scripts/build-ui-pi.sh builds on the Pi with glibc and GTK 4. It limits jobs based on available RAM.

The UI build reapplies patches/swift-cross-ui-pango-context.patch after dependency resolution to retain the Pango measurement optimization.

Kiosk Deployment

scripts/install-kiosk-pi.sh installs the fullscreen session and systemd restart behavior. The Pi currently uses cage/sway configuration to launch the release binary.

  • Build with CONFIG=release JOBS=1 for the shipping kiosk path.
  • Confirm the configured binary path before restarting the service.
  • Use grim over SSH for screenshots.
  • Use sway IPC for remote taps, but do not treat synthetic tap throughput as equivalent to real touch.

External Producers

producers/now-playing-push.py sends macOS now-playing state to the Pi; install-nowplaying-agent.sh installs its launch agent.

Restart after reboot or failure must be verified operationally.

Operational Safety Notes

  • The ingest server is trusted-LAN only unless hardened behind a secure boundary.
  • Native Pi release builds are slow and memory-sensitive; use one build job.
  • Tar-based deploys do not delete renamed files and can leave duplicate Swift declarations.
  • macOS tar can create AppleDouble files unless COPYFILE_DISABLE=1 is set.
  • The SwiftCrossUI dependency patch may stop applying after an upstream version change; inspect warnings.

Key Points

  • GTK requires a separate native Pi build.
  • Tests do not yet prove external package consumption.
  • Kiosk and ingest constraints are operational, not framework behavior.
