DeskDashboard / How-To

Connect HomePod Now Playing

Install pyatv with Python 3.12 on the Mac, find the HomePod ID, then install the agent with the Pi ingest URL.

Data Route

HomePod→pyatv on Mac→LaunchAgent every 5s→Pi :8642→Music tile

Install pyatv

1

Install pipx

brew install pipx
pipx ensurepath
2

Use Python 3.12

pipx install --python /opt/homebrew/opt/python@3.12/libexec/bin/python3 pyatv

pyatv 0.18 crashes on Python 3.14 and may report “nothing playing.”

Find the HomePod

3

Scan the network

atvremote scan
4

Copy its ID

Set it as DD_ATV_ID.

Install the Push Agent

5

Point it at the Pi

DD_ATV_ID= \
DD_INGEST_URL=http://:8642/ingest/now-playing \
bash producers/install-nowplaying-agent.sh
6

Watch the log

tail -f /tmp/deskdashboard-nowplaying.log

Verify

  • A JSON line appears about every 5 seconds.
  • The response includes "stored".
  • Music updates the Pi tile.
  • The URL names the Pi, not Mac localhost.

Troubleshoot “Nothing Playing”

1

Query pyatv

~/.local/bin/atvscript --id  playing
2

Read errors

tail -100 /tmp/deskdashboard-nowplaying.err
3

For an event-loop traceback, reinstall with Python 3.12

pipx uninstall pyatv
pipx install --python /opt/homebrew/opt/python@3.12/libexec/bin/python3 pyatv

Key Facts

Mac producer → Pi ingest server on port 8642. pyatv requires Python 3.12.

Done When

HomePod music appears on the Pi within about five seconds.
