Connect HomePod Now Playing

One-sentence version: Install pyatv with Python 3.12 on the Mac, discover the HomePod ID, then run the installer with the Pi ingest URL.

Source checkedLow-reading layout360px ready

Know the Route

HomePod→pyatv on Mac→LaunchAgent every 5s→Pi :8642→Music tile

Install the Reader

1

Install pipx

brew install pipx
pipx ensurepath
2

Pin pyatv to Python 3.12

pipx install --python /opt/homebrew/opt/python@3.12/libexec/bin/python3 pyatv
Version trap

pyatv 0.18 crashes on Python 3.14. The symptom may look like “nothing playing.”

Find the HomePod

3

Scan the network

atvremote scan
4

Copy the HomePod ID

You will use it as DD_ATV_ID.

Install the Push Agent

5

Point it at the Pi

DD_ATV_ID= \
DD_INGEST_URL=http://:8642/ingest/now-playing \
bash producers/install-nowplaying-agent.sh
6

Watch the log

tail -f /tmp/deskdashboard-nowplaying.log

What Success Looks Like

  • A producer JSON line appears about every 5 seconds.
  • The response includes "stored".
  • Playing music changes the Pi tile.
  • The ingest URL names the Pi—not 127.0.0.1 on the Mac.

If It Says “Nothing Playing”

1

Query pyatv directly

~/.local/bin/atvscript --id  playing
2

Read the error log

tail -100 /tmp/deskdashboard-nowplaying.err
3

Reinstall on Python 3.12 if there is an event-loop traceback

pipx uninstall pyatv
pipx install --python /opt/homebrew/opt/python@3.12/libexec/bin/python3 pyatv

Remember Only 3 Things

  1. The producer runs on the Mac; the ingest server runs with the displayed dashboard.
  2. Pin pyatv to Python 3.12.
  3. For a Pi-hosted UI, the producer URL must point to the Pi’s port 8642.

What To Do Next

You are done when…

Music playing on the HomePod appears on the Pi within one producer interval—about five seconds.
