Add a Theme, Tile Layout, or Board

One-sentence version: Pick the layer that owns the change—theme for tokens, WidgetLayout for one tile, or app-side board files for the whole screen.

Make a Theme

1

Copy one nearby theme

Create one file under Theme/Themes. Keep its named color/type/shape tokens beside the theme.

2

Declare only the differences

public struct MyTheme: Theme, Sendable {
    public let name = "My Theme"
    public var colors: ThemeColors { .myPalette }
    public init() {}
}
3

Use it at composition or arrangement

The composition supplies the default. A specific Arrangement may override it.

Native font trap

fontFamily reaches the dev web renderer only. The Pi’s native font comes from GTK settings.

Make a Tile Layout

1

Create one new layout file

Do not add an enum case. WidgetLayout is a struct with named static values.

2

Map content to semantic nodes

public extension WidgetLayout {
    static let myLayout = Self(id: "myLayout") { content in
        .stack(.vertical, spacing: 6, [
            .text(content.primaryText, role: .hero)
        ])
    }
}
3

Select it on the widget

Use .layout(.myLayout). Existing renderers interpret the same semantic tree.

GTK interaction rule

Do not swap the node structure while a press is active. Keep tappable structure stable; change strings and state.

Make or Change a Board

1

Edit an app-side board file

Board geometry is a product decision. Use the BoardColumn, BoardRow, and BoardBand DSL in the app.

2

Add it to Arrangements.swift

The array order is the switcher order. Index 0 is what the kiosk boots into.

3

Verify at the target shape

swift run deskdashboard-ui --window 1920x440

Visual Checkpoints

  • Text still fits at 1920×440.
  • Bottom margin is visible.
  • Touch targets stay usable.
  • Theme contrast works on the physical panel.
  • Switcher order matches Arrangements.swift.

Remember Only 3 Things

  1. Theme = tokens; WidgetLayout = one tile’s semantic tree; board = whole-screen geometry.
  2. A new WidgetLayout is a standalone static value in its own file, not an enum case.
  3. The physical Pi panel—not a desktop preview—is the final color and geometry check.
