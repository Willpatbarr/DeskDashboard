Add a Widget

Choose the smallest pattern, build data → transform → display, then wire it in Composition.swift.

Choose a pattern

Simple

Static or self-contained

Use RenderableWidget. Skip service and model.

Data-backed

Service data

Use Service → WidgetModel → ServiceBackedWidget.

Push

POST data

Add a locked store and ingest route.

Build in order

1

Define the raw data contract

Make a Sendable value, a service protocol, and a typed ServiceKey. Store canonical values—not display strings.

2

Add a simulated fallback

Return believable data with no network or hardware. This keeps development fast and the tile non-empty.

3

Transform in the model

Put units, formatting, staleness, and cheap per-tick refresh here. Keep UI imports out.

4

Render semantic content

Return WidgetContent. Choose a preset with .layout(.bigNumber) or another named layout.

5

Wire the running app

Add the service and widget in Sources/App/DeskDashboardComposition/Composition.swift.

6

Only for push data

Add the POST route in Sources/App/DeskDashboardIngest/PushIngest.swift. Protect shared state with a lock.

7

Prove the behavior

Add model/widget tests, run the suite, then inspect the tile in the browser or native UI.

swift test
swift run deskdashboard-dev

Check

  • No AppKit, HomeKit, or GTK in the service.
  • The model owns display formatting.
  • The widget returns semantic content, not fonts or pixels.
  • A simulated service works offline.
  • Composition.swift contains the live instance.
  • Tests cover missing data and the happy path.

Blank tile

No model value

Make activate() refresh immediately; ticks wait for the clock.

Wrong service

Resolution order is direct binding → environment service → fallback.

No push data

POST to the displaying Pi or dev app on port 8642.

Key facts

  • Use three layers only for data or transformation work.
  • Service stores facts; model formats; widget creates WidgetContent.
  • Composition.swift wires the app.

Done when

  • Offline data renders.
  • Real data replaces it.
  • swift test passes.
